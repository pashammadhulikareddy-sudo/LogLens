
# LogLens - Security Log Analysis System

## Project Description
LogLens is a beginner-friendly security log analysis
system that detects suspicious login activities
and common web attack patterns.

## Features
- Security log file upload
- Successful and failed login analysis
- Suspicious IP detection
- SQL Injection detection
- Cross-Site Scripting (XSS) detection
- Directory Traversal detection
- Severity classification
- Security dashboard
- Downloadable security report

## Technologies Used
- Python
- Google Colab
- Gradio
- Matplotlib

## How It Works
1. Upload a security log file.
2. LogLens analyzes the log entries.
3. Suspicious activities are identified.
4. Attack types and severity are displayed.
5. Download the security report.

## Project Status
Working prototype. Detection currently uses
sample log formats and predefined patterns.
